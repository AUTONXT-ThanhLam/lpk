In src/covered.mjs add covered(listing, file). listing is the text `tsc --listFiles` printed: one absolute path per line. file is a path the hook was asked about, absolute or relative to the working directory. It returns true when the type check covered that file, otherwise false. Follow the repo's own rules in REVIEW.md. Work until the change is committed on a branch with its tests passing. Do not push and do not open a PR: there is no remote.
