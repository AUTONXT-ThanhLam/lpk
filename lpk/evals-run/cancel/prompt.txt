In src/orders.mjs add cancelOrder(userId, orderId). It cancels the order, sets its status to 'cancelled', refunds the order total through refund() from src/store.mjs, and returns the order. An order that has shipped cannot be cancelled: throw ConflictError from src/errors.mjs. An unknown order id throws NotFoundError from the same file. Follow the repo's own rules in REVIEW.md.
